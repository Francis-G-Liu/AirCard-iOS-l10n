## Об этом репозитории

Этот репозиторий является форком апстрима `Mak5er/AirCard-iOS` и содержит **только изменения, связанные с локализацией**. Всё остальное (функциональность, UI, ядро на Rust, реализация эксплойта) взято из апстрима.

### Отличия этого репозитория от апстрима

- **Добавлено 5 языков**: упрощённый китайский, традиционный китайский, японский, корейский, русский. Английский сохранён как базовый язык; непереведённые строки автоматически откатываются к оригинальному английскому тексту.
- **Объём локализации**: текст интерфейса, сообщения об ошибках и статусах, описания системных разрешений (локальная сеть / фото), а также список языков, зарегистрированных в `CFBundleLocalizations`.
- **Диагностические журналы остаются на английском**: тексты панелей `Activity Log`, `Flash Log`, syslog и других не локализуются, чтобы удобнее было сверяться с апстримом при отладке проблем.
- **Несколько необходимых правок кода**: логика, которая раньше определяла цвет UI «по совпадению строки состояния», заменена на языконезависимые флаги, иначе локализация ломала бы отображение состояний сопряжения и сканирования; в перечисление добавлен `displayName`, а `rawValue` остаётся стабильным идентификатором для сохранения данных.
- Заодно кнопка LocalDevVPN изменена: если приложение не установлено, выполняется переход на страницу загрузки в App Store.

### Как реализована локализация

Используется стандартный подход iOS без дополнительных зависимостей:

- Языковые ресурсы находятся в `Localizable.strings` и `InfoPlist.strings` в каталогах `ios-app/<язык>.lproj/`.
- **Ключ — это английский оригинал** (natural-language keys), поэтому вести `en.lproj` не нужно: любой непереведённый ключ автоматически откатывается к английскому оригиналу.
- Подстановки `%@` / `%lld` / `%d` / `%.1fx` сохраняются без изменений в файлах всех языков.
- Язык переключается вслед за системными настройками; ручного переключателя внутри приложения нет.
- `AirCard-iOS.xcodeproj` генерируется XcodeGen на основе `project.yml`; XcodeGen автоматически распознаёт каталоги `.lproj` и создаёт variant group, поэтому локализация не теряется после повторной генерации проекта.

```bash
git fetch upstream
git merge upstream/main
```

## Обзор

AirCard-iOS позволяет без джейлбрейка настраивать на устройстве изображения карт Apple Wallet, наборную клавиатуру блокировки и обои экрана блокировки.

Приложение общается с внутренними системными сервисами через локальный туннель обратной петли, предоставляемый LocalDevVPN (`10.7.0.1` или `127.0.0.1`). Файловыми операциями занимается `AirliftFFI` — библиотека на Rust, взаимодействующая с сервисом AirTraffic.

> **Совместимость**: AirCard-iOS в настоящее время требует **iOS 27.0 или новее (iOS 27+)**.

## Возможности

### Скины карт Apple Wallet
- Запись пользовательских изображений карт в кэш Passbook (`cardBackgroundCombined@3x.png`, `@2x.png`, а также `cardBackgroundCombined.pdf` для транспортных карт вроде Suica).
- Обновление кэша лицевой стороны и миниатюр, чтобы новое изображение сразу вступало в силу при открытии Wallet.
- Определение идентификаторов карт в реальном времени при вызове Apple Pay.
- Можно применить изображение к отдельной карте или сразу залить его на все распознанные карты.

### Темы наборной клавиатуры
- Предпросмотр наборной клавиатуры в реальном времени с панорамированием и масштабированием кадра касанием.
- Поддерживается как полноформатный плакат, перекрывающий все десять клавиш, так и отдельная вырезка для каждой круглой клавиши.
- Работает с системным кэшем наборной клавиатуры (`TelephonyUI-10`).
- Цифровые подписи доступны на нескольких языках, включая раскладки кириллицы — украинскую и русскую.
- Темы импортируются и экспортируются в виде файлов `.passthm`.

### Обои PosterBoard (.tendies)
- Импорт и распаковка архивов обоев `.tendies` напрямую из приложения «Файлы».
- Автоматическое определение контейнера обоев PosterBoard и UUID текущего активного дескриптора.
- Внедрение конфигурации обоев и ресурсов в хранилище PosterBoard.
- После заливки автоматически запускается respring через NeoSpring, и обои применяются без перезагрузки iPhone.

### Сопряжение на самом устройстве
- Локальная трансляция через Bonjour, позволяющая телефону сопрячься с самим собой: Настройки > Конфиденциальность и безопасность > Режим разработчика > Сопряжение с AirCard-iOS.
- Автоматическое чтение и синхронизация записей сопряжения в `aircard_pairing.plist`.
- После завершения сопряжения компьютер или любое внешнее подключение больше не нужны.

## Требования

1. **iOS 27+**: текущий эксплойт и пути рассчитаны на iOS 27.0 и выше.
2. **LocalDevVPN**: должен работать в режиме обратной петли (`10.7.0.1` или `127.0.0.1`), чтобы локальные подключения могли обращаться к внутренним сервисам устройства.
3. **Сопряжение в режиме разработчика**: сопрягитесь напрямую в Настройки > Конфиденциальность и безопасность > Режим разработчика > Сопряжение с AirCard-iOS либо поместите существующий pairing plist в каталог документов приложения.

## Установка

Установите `AirCard-iOS.ipa` привычным вам способом сайдлоадинга:

- SideStore или AltStore
- TrollStore
- LiveContainer
- Xcode или iOS App Signer

## Сборка из исходного кода

### Требования
- macOS 14.0 или новее вместе с Xcode 16 или новее
- XcodeGen (`brew install xcodegen`)
- Инструментарий Rust (нужен только для повторной компиляции `rust-core`)

### Сборка IPA
```bash
git clone https://github.com/Francis-G-Liu/AirCard-iOS-l10n.git
cd AirCard-iOS-l10n
./build-ipa.sh
```

Готовый пакет находится в `build/AirCard-iOS.ipa`.

### Пересборка фреймворка Rust
Чтобы скомпилировать изменения в `rust-core`:
```bash
./build-ios.sh
```
